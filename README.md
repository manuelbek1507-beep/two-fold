# 2 Fold 🌎💕

A private, installable web app for two approved partners.

**Features**
- End-to-end encrypted chat
- Shared memories and letters
- Shared playlist with background playback
- Voice and video calls
- Installable Progressive Web App (PWA)

**Tech stack:** React, TypeScript, Vite, Supabase, and Netlify.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

The app is configured for Netlify. Build command: `npm run build`. Publish directory: `dist`.

See `CHECKLIST.md` and the `docs/` folder for setup, security, and testing details.
